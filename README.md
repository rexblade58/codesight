# CodeSight

Code quality analyzer that scans projects for metrics, issues, and complexity scores.

## Quick Start

```bash
git clone https://github.com/rexblade58/codesight.git
cd codesight
node src/cli.js analyze /path/to/project
```

## Metrics

Files, lines, functions, comments, issues, imports, exports

## Quality Grades

A (90-100)  B (75-89)  C (60-74)  D (40-59)  F (0-39)
